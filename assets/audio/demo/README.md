# Áudio demo e integração

Os arquivos de demonstração técnica desta pasta validam a infraestrutura de áudio local. Não definem voz, interpretação, roteiro ou direção sonora de um curso real.

`instruction_a_demo.wav` é uma fala técnica em português do Brasil, gerada para provar o fluxo conteúdo → `CourseAudioOrchestrator` → `AudioGuidance` → asset. Ela deve ser substituída quando houver produção e revisão pedagógica do áudio definitivo.

`technical_signal_demo.wav` é um sinal curto e neutro usado somente para validar o canal de SFX na integração técnica.

`stella/m1c1-stella.mp3` é a gravação associada à fala canônica de Stella na Missão 1.0 do Módulo 1; o texto continua disponível para leitura acessível e fallback.
