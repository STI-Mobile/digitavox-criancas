# Áudio técnico de demonstração

Os arquivos desta pasta existem somente para validar a infraestrutura de áudio local. Não são conteúdo pedagógico aprovado nem definem voz, interpretação, roteiro ou direção sonora do curso Exploradores Espaciais.

`instruction_a_demo.wav` é uma fala técnica em português do Brasil, gerada para provar o fluxo conteúdo → coordenação → player → asset. Ela deve ser substituída quando houver produção e revisão pedagógica do áudio definitivo.
